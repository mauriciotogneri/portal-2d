## Run 3 in detail

The box run: turning in place, and doors several buttons link. Two chambers, a teach and a combine, the combine sketched first, in the idea pool (guideline 51), not the four to six guessed: each chamber must force something no earlier route did and look like no earlier move (guideline 113), and the outline's other run 3 goals would read as an earlier chamber again or can only be offered, so they wait for later runs (run 3's paragraph above). | 6   | A shot missing on the walls facing a door, before any chamber relies on them         | Run 5           | A refused shot can only be offered, never forced (guideline 108); run 5 makes the same rule matter behind an end plate, and no run 4 chamber relies on those walls before then                                             |

The order: 3.1 comes straight after 2.4, a short chamber with one new move after a hard one (guideline 46); 3.2 comes after it without rehearsing its own key move (guideline 47).

Left out:

- A teach chamber of its own for the door several buttons link: decision 1.
- A twist: none found that forces something new and reads as new (guideline 113). The candidates were the subject standing in for a box on a door's second button, which then needs a shot through the door it holds (chamber 2.4), and rows 3 and 4.
- A test of turning in place: a player can't get through 3.1 without the turn key, so a test has nothing left to check (guideline 24).
- Turning in place to shoot along a line with no run-up: the same key, so no chamber of its own; from 3.1 on, a route may need it (guideline 66).
