## Run 5 in detail

The steel run: blocked walls a button opens, and the laser. Three chambers, a teach, a twist and a combine, the combine sketched first, in the idea pool (guideline 51), each forcing something no earlier route did (guideline 113), not the four to six guessed: the outline's other run 5 goals either read as an earlier chamber here or need an element that makes them more than a door, so they wait for it (run 5's paragraph above). The twist forces a box sent home from elsewhere, carried here from run 4 (guideline 28), and shows a portal on steel closing as the steel shuts, as no loss, before the combine relies on it (guideline 25). The laser is met in all three as the barrier a shot crosses and the subject doesn't, an open ditch's part, which run 1 taught, so in run 5 it does nothing an open ditch wouldn't (guideline 17, bent on purpose: it is met here so that runs 6 and 7 can use it as a barrier before run 8's light barrier, which stops shots, and run 9's slides set it apart), and in 5.1 it is a second new element beside the steel (guideline 24, bent on purpose: it asks for no rule the player hasn't met, only a new look, though its glow draws the eye from the steel, guideline 20, which the steel's antline offsets). Turning in place is known from run 3, so a route may need the turn key (guideline 66). Hints stay in run 1 (convention 7).
