## Run 4 in detail

The switch run, and the box that starts absent. Three chambers, two teaches and a combine, the combine sketched first, in the idea pool (guideline 51), each forcing something no earlier route did (guideline 113). No test of the switch: no player gets through 4.1 without using its switch, and the switch alone has no consequence left for a test to check (guidelines 42 and 113). The door or exit a switch and a button link is first met in the combine, its antlines showing which input is still to go, as run 3 met the door two buttons link in its combine. One box for two buttons in turn, carried forward from run 3, is forced in 4.3. A switch refuses a carried box and never takes one put down, refusals no route can be made to meet (guideline 108), so run 4 keeps its switches off the tiles where a box goes down (guideline 80). Hints stay in run 1 (convention 7): the controls legend says the interact key uses switches.

Left out:

- A test of the switch: rows 1 and 2 are forced in 4.1, and nothing else about a lone switch is left to test (guideline 42).
- A test of the box that starts absent: once in, it is a box like any other, so a test would repeat 4.2.
- A teach of its own for the door a switch and a button link: decision 2.
- A switch as a rescue for a stranded box (the patterns' "Progress latch" and "Box as one-way recall"): a tool for recovery in later chambers, not a lesson.
