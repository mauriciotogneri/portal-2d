## Run 4 in detail

The switch run. Three chambers, a teach, a show and a combine, the combine sketched first, in the idea pool (guideline 51), each forcing something no earlier route did (guideline 113). No test: no player gets through 4.1 without using its switch, and the switch alone has no consequence left for a test to check (guidelines 42 and 113). The door or exit a switch and a button link is first met in the combine, its antlines showing which input is still to go, as run 3 met the door two buttons link in its combine. One box for two buttons in turn, carried forward from run 3, is forced in 4.2. A switch refuses a carried box and never takes one put down, refusals no route can be made to meet (guideline 108), so run 4 keeps its switches off the tiles where a box goes down (guideline 80). Hints stay in run 1 (convention 7): the controls legend says the interact key uses switches.
