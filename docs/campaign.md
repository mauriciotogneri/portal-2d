# Campaign

The plan for the campaign's chambers: the conventions every chamber keeps, every run in the order its elements arrive and what each run teaches, and the next run chamber by chamber. It names what each chamber should teach, never its key move, layout or route: those are in its notes under `docs/spoilers/`, which the author reads only after playing it cold. How to design a chamber is in `docs/level_design.md`; where the work stands is in `todo/campaign.md`.

**Before detailing a run or designing a chamber, read `docs/level_design.md` carefully, in full, and follow everything in it.** Read it again each time, not from memory, since it grows with every chamber, and read all of it, not only the sections that seem to apply: a guideline in one section often bears on a choice in another. Every `Must` holds for every chamber, broken only on purpose with the reason written in the chamber's notes; every `Should` is followed unless the notes say why another guideline serves the chamber better. A chamber is ready for the author only once it has passed every check that comes before the author's play under "Checking a chamber" there (guidelines 100–104 and 110).

Each run follows the handbook's four parts (guideline 41): teach, test, twist, combine. The rules each run teaches are named here; how a twist chamber turns them is not.

## Conventions

What every chamber keeps, so the player can trust it (the campaign intro of `docs/level_design.md`). Break one only in a chamber whose notes say why, and make the break plain.

| #   | Convention                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------------- |
| 1   | Every box in a chamber is needed                                                                                           |
| 2   | Every element matters: each is used, or blocks a shortcut, and nothing is a decoy                                          |
| 3   | Every link has an antline, from each button, switch or receiver to what it links (guideline 96)                            |
| 4   | Steel, a blocked wall with no link, never takes a portal; a blocked wall that can open always has an antline leading to it |
| 5   | What holds the exit shut is in view from the start, with an antline from what opens it                                     |
| 6   | A chamber is no larger than its puzzle needs (guideline 99)                                                                |
| 7   | Hints, if they are built, appear only in run 1, and only say what an element is or does (guideline 31)                     |

About 40 to 60 chambers in all, a guess that each run's detailing will correct (guideline 42). The heavy runs (9 and 10) sit between lighter ones, so the pace rises and falls (guideline 46), and each run brings something new.

### 1. First steps (the tutorial)

The core verbs, one at a time, in small rooms: walking to the exit; shooting a portal of each colour onto a plain wall and crossing between them; steel takes no portal; a ditch stops the subject but not a shot; a button opens what its antline leads to while something stands on it, and a box can stand there for the subject; a box can be carried through portals, and the portal keys don't shoot while one is carried. Mostly teach chambers, ending in one combine. Detailed [below](#run-1-in-detail).

### 2. Portals in depth

The portal with no new element: a door shutting closes no portal, and either portal can be the way in. One chamber, built as 2.4. Three more, a test and two twists, were built and cut on the author's cold play (2026-11-23): each played as a simpler chamber 1.4, its lesson a refusal a route could avoid or a forced move that read as an old one (guideline 113). Their lessons that later chambers need moved to run 3's outline, which kept one and carried the rest forward. Detailed [below](#run-2-in-detail).

### 3. Boxes and buttons

What a box can and can't do: putting it down on any side by turning in place, the move the controls hide (guideline 29); a box bars the tile it rests on; a door several buttons link opens only while all of them are held, every antline lit (guideline 62). A teach and a combine. Carried forward to a later run whose new element can force them without reading as an earlier chamber (guideline 113): one box for two buttons in turn, and the portal just come out of forced to move by a box in front of it (guideline 27; run 2's cut 2.3 forced it and read as chamber 1.4). The walls facing a door move to run 5. Detailed [below](#run-3-in-detail).

### 4. Switches

The switch: it stays on from its first use, so it can't be undone; a door a switch and a button link; a switch linked to a box sends it home. And the box that starts absent, which a link brings in on its start tile the first time it sends it home (decision 12 of `todo/campaign.md`). Two teaches and a combine. One box for two buttons in turn, carried forward from run 3, is forced here. Carried forward again: the portal just come out of, forced to move by a box in front of it; and a used switch acting again on each use, which a later chamber shows before any relies on it (guideline 27: "it stays on" can read as "it is spent"). No run 4 route is forced to send a box home from elsewhere, so a later chamber forces it before any relies on it, run 5 at the latest (guideline 28). No run 4 chamber relies on the walls facing a door refusing portals, which run 5 leaves to guideline 75. Detailed [below](#run-4-in-detail).

### 5. Lasers, and walls that switch

The laser stops the subject but not a shot, as an open ditch does; steel takes portals while a button holds it, and a portal on it closes as it shuts, where one past a door outlasts the door; a switch linked to a box sends it home from wherever it lies, and the box isn't lost (carried from run 4). A teach, a twist and a combine. Carried forward: a laser a link switches, which until slides plays a door's part for the subject and an open ditch's for shots, to run 9; a ditch a link switches, whose one consequence a door hasn't, a box lying on it falling as it opens, needs a second box to hold its button, since the subject can't hold a button beside what it links (guideline 59), to run 10, where a receiver's ray lets one box do it; and, still, the portal just come out of, forced to move by a box in front of it (from run 3), and a used switch acting again (from run 4). The walls that take no portal behind a laser's end plate and facing a door can't be forced (guideline 108) and are left to guideline 75 in every chamber. Detailed [below](#run-5-in-detail).

### 6. Fizzlers

Walking into a fizzler that is on closes both portals and breaks up a carried box, which flies home; shots don't pass one, and the portal keys do nothing inside one; a fizzler switching on closes a portal facing it; the walls behind its connectors take no portal.

### 7. Arrows

An arrow lets the subject on only its way, and on it the subject faces only that way; a link turns an arrow, which turns back when the link lets go, even under the subject. Arrows are valves: a run of them is a one-way road.

### 8. Light barriers

The light barrier stops the subject and shots, where a laser stops only the subject, and switches like a door; a short run, set against run 5's lasers (guideline 17).

### 9. Slide floors

A slide stops only where something stops it: a wall, a box, plain floor, a closed door, a light barrier or a laser that is on; a box placed as a stopper; a slide into a portal comes out heading the way the other portal faces; a button slid over isn't pressed; a fizzler on a slide's way fizzles the subject and the slide goes on; a laser a link holds off lets a slide over slide floor go on, where an open door stops it (carried from run 5). Combines with runs 6 to 8.

### 10. Rays

An emitter's ray lights a receiver, which holds its links open while lit; the subject and a resting box cut a ray, and a ray goes through portals as the subject does; a closed door and a light barrier that is on stop it; a ray must stay off what its own receiver holds (guideline 92). A ditch a link switches comes here: a box lying on it falls as the ray is cut and the ditch opens, which one box can show (carried from run 5). The solver's macro search refuses chambers with receivers, so these are checked by hand.

### 11. Mirror boxes

A resting mirror box turns a ray a quarter turn; mirror box and portal pair as the two ways to bend a ray; one box with two jobs.

### 12. Finale

Nothing new: chambers that make the campaign's elements act on each other, ending in a last chamber of synthesis and spectacle whose catch is no harder than the run before it (guideline 50).

## Run 5 in detail

The steel run: blocked walls a button opens, and the laser. Three chambers, a teach, a twist and a combine, the combine sketched first, in the idea pool (guideline 51), each forcing something no earlier route did (guideline 113), not the four to six guessed: the outline's other run 5 goals either read as an earlier chamber here or need an element that makes them more than a door, so they wait for it (run 5's paragraph above). The laser is met in all three as the barrier a shot crosses and the subject doesn't, an open ditch's part, which run 1 taught, so in run 5 it does nothing an open ditch wouldn't (guideline 17, bent on purpose: it is met here so that runs 6 and 7 can use it as a barrier before run 8's light barrier, which stops shots, and run 9's slides set it apart), and in 5.1 it is a second new element beside the steel (guideline 24, bent on purpose: it asks for no rule the player hasn't met, only a new look, though its glow draws the eye from the steel, guideline 20, which the steel's antline offsets). 5.2 has five kinds of element (guideline 18, bent on purpose: the laser is the only barrier a shot crosses and the subject doesn't, and 5.2 plays as a flow). Turning in place is known from run 3, so a route may need the turn key (guideline 66). Hints stay in run 1 (convention 7). Drafted from a proposal two fresh reviewers checked, one against the handbook and one on the prototypes alone, the twist coming from the first; approved by the author on 2026-11-23, with the laser kept in run 5, the switched laser and ditch carried to runs 9 and 10, 5.1 kept as a teach of its own though it may read as an earlier chamber (as cut 2.2 did), its keeping to be judged on the author's cold play, both bends accepted, and all three designed before the author plays any.
