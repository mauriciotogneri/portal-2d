# Campaign

The plan for the campaign's chambers: the conventions every chamber keeps, every run in the order its elements arrive and what each run teaches, and the next run chamber by chamber. It names what each chamber should teach, never its key move, layout or route: those are in its notes under `docs/spoilers/`, which the author reads only after playing it cold. How to design a chamber is in `docs/level_design.md`; where the work stands is in `todo/campaign.md`.

**Before detailing a run or designing a chamber, read `docs/level_design.md` carefully, in full, and follow everything in it.** Read it again each time, not from memory, since it grows with every chamber, and read all of it, not only the sections that seem to apply: a guideline in one section often bears on a choice in another. Every `Must` holds for every chamber, broken only on purpose with the reason written in the chamber's notes; every `Should` is followed unless the notes say why another guideline serves the chamber better. A chamber is ready for the author only once it has passed every check that comes before the author's play under "Checking a chamber" there (guidelines 100–104 and 110).

Each run follows the handbook's four parts (guideline 41): teach, test, twist, combine. The rules each run teaches are named here; how a twist chamber turns them is not.

## Conventions

What every chamber keeps, so the player can trust it (the campaign intro of `docs/level_design.md`). Break one only in a chamber whose notes say why, and make the break plain.

### 1. First steps (the tutorial)

The core verbs, one at a time, in small rooms: walking to the exit; shooting a portal of each colour onto a plain wall and crossing between them; steel takes no portal; a ditch stops the subject but not a shot; a button opens what its antline leads to while something stands on it, and a box can stand there for the subject; a box can be carried through portals, and the portal keys don't shoot while one is carried. Mostly teach chambers, ending in one combine. Detailed [below](#run-1-in-detail).

### 2. Portals in depth

The portal with no new element: a door shutting closes no portal, and either portal can be the way in. One chamber, built as 2.4. Three more, a test and two twists, were built and cut on the author's cold play (2026-11-23): each played as a simpler chamber 1.4, its lesson a refusal a route could avoid or a forced move that read as an old one (guideline 113). Their lessons that later chambers need moved to run 3's outline, which kept one and carried the rest forward. Detailed [below](#run-2-in-detail).

### 3. Boxes and buttons

What a box can and can't do: putting it down on any side by turning in place, the move the controls hide (guideline 29); a box bars the tile it rests on; a door several buttons link opens only while all of them are held, every antline lit (guideline 62). A teach and a combine. Carried forward to a later run whose new element can force them without reading as an earlier chamber (guideline 113): one box for two buttons in turn, and the portal just come out of forced to move by a box in front of it (guideline 27; run 2's cut 2.3 forced it and read as chamber 1.4). The walls facing a door move to run 5. Detailed [below](#run-3-in-detail).

### 4. Switches

The switch: it stays on from its first use, so it can't be undone; a door a switch and a button link; a switch linked to a box sends it home. And the box that starts absent, which a link brings in on its start tile the first time it sends it home (decision 12 of `todo/campaign.md`). Two teaches and a combine. One box for two buttons in turn, carried forward from run 3, is forced here. Carried forward again: the portal just come out of, forced to move by a box in front of it; and a used switch acting again on each use, which a later chamber shows before any relies on it (guideline 27: "it stays on" can read as "it is spent"). No run 4 route is forced to send a box home from elsewhere, so a later chamber forces it before any relies on it, run 5 at the latest (guideline 28). No run 4 chamber relies on the walls facing a door refusing portals, which run 5 leaves to guideline 75. Detailed [below](#run-4-in-detail).

### 5. Lasers, and walls that switch

The laser stops the subject but not a shot, as an open ditch does; steel takes portals while a button holds it, and a portal on it closes as it shuts, where one past a door outlasts the door. A teach and a combine: the twist, built as 5.2, was cut on the author's cold play (2026-11-23) for reading as 5.1 (guideline 113). Carried forward: a switch linked to a box sending it home from wherever it lies, the box not lost, which the cut twist forced (carried from run 4), to run 6; a laser a link switches, which until slides plays a door's part for the subject and an open ditch's for shots, to run 9; a ditch a link switches, whose one consequence a door hasn't, a box lying on it falling as it opens, needs a second box to hold its button, since the subject can't hold a button beside what it links (guideline 59), to run 10, where a receiver's ray lets one box do it; and, still, the portal just come out of, forced to move by a box in front of it (from run 3), and a used switch acting again (from run 4). The walls that take no portal behind a laser's end plate and facing a door can't be forced (guideline 108) and are left to guideline 75 in every chamber. Detailed [below](#run-5-in-detail).

### 6. Fizzlers

Walking into a fizzler that is on closes both portals and breaks up a carried box, which flies home; shots don't pass one. A teach and a test. A box sent home from elsewhere, carried from runs 4 and 5, is forced, as no loss (guideline 28). Refusals no route can be made to meet (guideline 108): the portal keys doing nothing inside one, the walls behind its connectors taking no portal, and a box picked up from inside one breaking up. Carried forward: a fizzler a link switches, which closes a portal facing it and breaks up a box lying in it as it switches on, to run 10, where a receiver's ray can switch one: in run 6 the first would read as run 5's steel shutting on its portal and the second would repeat the send-home 6.1 forces (guideline 113); a box flying home from far off, which run 6 shows only from close by, before any route relies on a far start (guideline 70); and, still, the portal just come out of, forced to move by a box in front of it (from run 3), and a used switch acting again (from run 4). Detailed [below](#run-6-in-detail).

### 7. Arrows

An arrow lets the subject on only its way, and on it the subject faces only that way; a link turns an arrow, which turns back when the link lets go, even under the subject. Arrows are valves: a run of them is a one-way road. Two teaches, with no twist or combine: a twist, built as 7.3, was cut before the author played it for reading as 7.2 reversed, in the same room shape (guideline 113), and the two combines sketched read as earlier chambers, one riding an arrow whose button lies right behind it, Playground 8's move, which the author played as the old campaign's chamber 7, the other sending a box home with a fizzler, as chamber 6.1 does (guideline 113), so run 8's combine serves arrows too (guideline 42). Refusals no route can be made to meet (guideline 108): a portal facing an arrow tile letting the subject only out, and a box resting on an arrow lifted only from the tile behind it. Carried forward: on an arrow the subject faces only its way, which the cut 7.3 meant to force, to a later run that forces the way round it, a put-down or a shot the player plans to the side refused (guideline 108); and again, since no arrow chamber found forces them without reading as an earlier one, a box flying home from far off (from run 6), the portal just come out of, forced to move by a box in front of it (from run 3), and a used switch acting again (from run 4). Detailed [below](#run-7-in-detail).

### 8. Light barriers

The light barrier stops the subject and shots, where a laser stops only the subject, and switches like a door. Before slides and rays that is all a door does too: a closed door stops the subject and shots, a link switches it and a portal shot past it outlasts it, and a fizzler that is on stops shots as well; a light barrier differs from a door only in which walls take portals (those alongside it do, those behind its end plates don't), which no route can be made to need (guideline 108). So run 8 is one chamber, a combine, which is both the light barrier's first contact, set against a laser (guideline 17), and run 7's missing combine, serving arrows too (guideline 42): one button linked to two elements, one of them an arrow it turns to close a way, the one thing a link can do only to an arrow. A teach was sketched with it and dropped before approval: its route was chamber 2.4's with the door a light barrier, and with the light barrier as floor it was chamber 1.1 with a laser (guideline 113). Refusals no route can be made to meet (guideline 108): a shot across a light barrier that is on, a crossing onto one that is on, and the walls behind its end plates. Carried forward: a light barrier switching on breaks up a box lying in it, as a door closing does, which with one box needs the subject holding its button beside it (guideline 59), to run 10, where a receiver's ray lets one box do it; and again a box flying home from far off (from run 6), the portal just come out of, forced to move by a box in front of it (from run 3), a used switch acting again (from run 4), and on an arrow the subject facing only its way (from run 7). If the author's cold play cuts the combine, run 8 has none, and the light barrier is first met in run 9, on slide floor, where neither a door nor a laser can do its job. Detailed [below](#run-8-in-detail).

### 9. Slide floors

A slide stops only where something stops it: a wall, a box, plain floor, a closed door, a light barrier or a laser that is on; a box placed as a stopper; a slide into a portal comes out heading the way the other portal faces; a button slid over isn't pressed; a fizzler on a slide's way fizzles the subject and the slide goes on; a laser a link holds off lets a slide over slide floor go on, where an open door stops it (carried from run 5). Combines with runs 6 to 8.

### 10. Rays

An emitter's ray lights a receiver, which holds its links open while lit; the subject and a resting box cut a ray, and a ray goes through portals as the subject does; a closed door and a light barrier that is on stop it; a ray must stay off what its own receiver holds (guideline 92). A ditch a link switches comes here: a box lying on it falls as the ray is cut and the ditch opens, which one box can show (carried from run 5). So does a fizzler a link switches: as it switches on it closes a portal facing it and breaks up a box lying in it, which sends the box home without the subject walking into a field, so its portals last (carried from run 6). So does a light barrier switching on as a ray is cut, breaking up a box lying in it, as a door closing does (carried from run 8). The solver's macro search refuses chambers with receivers, so these are checked by hand.

### 11. Mirror boxes

A resting mirror box turns a ray a quarter turn; mirror box and portal pair as the two ways to bend a ray; one box with two jobs.

### 12. Finale

Nothing new: chambers that make the campaign's elements act on each other, ending in a last chamber of synthesis and spectacle whose catch is no harder than the run before it (guideline 50).
